# p5.js 小演示

两幅用 [p5.js](https://p5js.org/) 画的浏览器素描。没有图片，也没有构建步骤：用浏览器打开对应的 HTML 即可。p5.js 从 jsDelivr 加载，第一次打开需要联网。

GitHub 的 Raw 链接只会给出源码，不会把画面跑起来。若仓库开了 GitHub Pages，夜湖在站点首页，自注意力在同目录的 `attention.html`。

## 夜湖 · `index.html`

湖边夜景：月亮、星星、远山、松林，湖面上有被波纹切断的月光，还有一只亮着灯、轻轻起伏的小船。圆、三角形、曲线和颜色都是代码画上去的。

### 怎么打开

1. 克隆或下载这个仓库。
2. 用浏览器打开 `index.html`（双击，或把文件拖进 Chrome、Edge、Firefox）。
3. 不需要安装 Node.js。

画面会铺满窗口。多看几秒：星星在闪，水面和船在慢慢动。

在线地址（需已开启 GitHub Pages）：

`https://yitom486.github.io/p5-drawing/`

### 这段代码在做什么

p5.js 在页面里放一块画布，让你用代码画画。`setup()` 只在开始时运行一次：创建跟窗口一样大的画布，并用固定的随机种子放好星星，所以每次打开都是同一片星空。`draw()` 大约每秒运行 30 次，按「远处先画、近处后画」铺上天空、月亮、远山、湖水、岸和船。水面的波光用 `noise()` 缓慢错开，星星的明暗和船的起伏用 `sin()` 轻轻摆动——画面在动，但仍然是同一幅安静的夜景。

## 自注意力 · `attention.html`

短句「我 / 喜欢 / 看 / 夜 / 湖」。每个词轮流当成**查询 Query**，去和所有词的**键 Key** 做比较。比较得到的点积分数再经过 softmax，变成**注意力权重**：都是正数，加起来等于 1。线越粗越亮，表示这个词越被留意。然后按权重把各个词的**值 Value** 加起来（**加权求和**），混成该词的新表示——画面里，值就是每个词自己的颜色，混色后的圆点就是新表示。

这些向量是手写的玩具，不是训练好的大模型。点积和 softmax 是真算的，所以连线粗细、百分比和右侧的注意力矩阵对得上。

### 怎么打开

用浏览器打开 `attention.html`。画面铺满窗口，大约每个词六秒，五个词轮完再循环。点击画面可以暂停。

在线的话，把 Pages 地址后面的文件名换成 `attention.html`。

### 这段代码在做什么

`setup()` 创建画布，并事先算好整张注意力矩阵。`draw()` 按时间走四步：点亮查询、画出和键的分数、收成 softmax 权重、把值加权求和。窗口变了会重排；宽屏时矩阵在右侧，窄屏时挪到词的下方。

## 文件

- `index.html` / `sketch.js`：夜湖。想改颜色，从 `sketch.js` 顶部的 `PALETTE` 开始
- `attention.html` / `attention.js`：自注意力。句子和向量在 `attention.js` 顶部的 `TOKENS`
