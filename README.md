# 夜湖

一幅用 [p5.js](https://p5js.org/) 画出来的湖边夜景：月亮、星星、远山、松林，湖面上有被波纹切断的月光，还有一只亮着灯、轻轻起伏的小船。

没有使用图片。圆、三角形、曲线和颜色都是代码画上去的。

## 怎么看

1. 克隆或下载这个仓库。
2. 用浏览器打开 `index.html`（双击，或把文件拖进 Chrome、Edge、Firefox）。
3. 不需要安装 Node.js，也没有构建步骤。p5.js 从 jsDelivr 加载，所以第一次打开时需要联网。

画面会铺满窗口。多看几秒：星星在闪，水面和船在慢慢动。

如果仓库开启了 GitHub Pages，也可以在线看：

`https://yitom486.github.io/p5-drawing/`

GitHub 的 Raw 链接只会给出源码，不会把这幅画跑起来。

## 这段代码在做什么

p5.js 在页面里放一块画布，让你用代码画画。`setup()` 只在开始时运行一次：创建跟窗口一样大的画布，并用固定的随机种子放好星星，所以每次打开都是同一片星空。`draw()` 大约每秒运行 30 次，按「远处先画、近处后画」铺上天空、月亮、远山、湖水、岸和船。水面的波光用 `noise()` 缓慢错开，星星的明暗和船的起伏用 `sin()` 轻轻摆动——画面在动，但仍然是同一幅安静的夜景。

## 文件

- `index.html`：页面，从 CDN 引入 p5.js
- `sketch.js`：整幅画。想改颜色，从文件顶部的 `PALETTE` 开始
